SCOPE & LIMITS

能力有边界，前提先说清楚

Super Time 处理的是本机已有的微信数据，不是微信客户端替代品，也不是开箱即用的云端 AI 服务。下面这些条件会直接影响能否使用与结果是否可靠。

使用前需要确认

PLATFORM

仅支持 Windows 10/11 x64 与 PC 微信 4.x。macOS、Linux、32 位 Windows 与手机端不在支持范围内。

DATA ACCESS

只处理你有合法访问权的数据。应用不登录微信、不需要账号密码；自动获取密钥通常要求微信正在运行，也可以手动填写。

NETWORK

本机解析不代表全程离线。AI、模型下载、更新检查、远程媒体、任务投递等都有出网点；应用没有全局出网开关，彻底断网需依赖系统防火墙或断开网络。

FIRST RUN

首次使用需要完成引导、隐私同意、许可证与微信数据目录配置。AI 模型与向量索引不是首次启动时自动完成的，需要你按需配置。

THIRD PARTY

Feather 发送端不在安装包内；RPA 厂商需要对应账号、凭据和权益。阿里云、来也、实在与八爪鱼 MCP 仍标记为实验性接入。

本地优先，不等于全程离线

本地解析、全文索引、检索与派生库在本机运行；需要联网的模型和媒体路径会单独说明。

外部通道要自行准备

模型、Webhook、RPA 凭据与 Feather 发送端由使用者配置，可用性取决于其服务与网络。

OCR 与 AI 图片是两条路

微信原生 OCR 在本机识别；点击 AI 会把图片发给当前多模态模型，结果需要人工核对。

非腾讯官方产品

Super Time 与腾讯无关联，未获其授权或背书；请遵守当地法律、微信用户协议与数据授权要求。

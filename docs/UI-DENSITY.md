# UI 密度规范：卡片与组件的紧凑化设计

> 目标：每个界面的**固定内容（页头 / 筛选区 / 统计区）尽量少占高度**，卡片与组件不浪费空间，
> 同时不破坏可读性、可点性与既有响应式/主题/无溢出验收。
> 本文是设计口径 + 验收判据 + 实施分层；配套工具 `npm run ui:density-audit`。
> 适用范围：`src/client/ui-wechat` 全部 38 页签 / 144 个面板视图（含手机浏览器模式）。

---

## 0. 一句话原则

**空间优先给「会变的内容」（列表、表格、图表、正文），固定 chrome 只保留「一眼需要」的信息；
同类信息合并成一行，能内联就不换行，能省略号就不换行，能折叠就不铺开。**

---

## 1. 可度量目标（密度审计口径）

在 1440×900 与 1280×800 两档实测（内容区 = 面板可见高度，不含 Electron 标题栏/侧栏）：

| 指标 | 定义 | 目标（1440×900） | 目标（1280×800） |
|---|---|---:|---:|
| **固定区占比** `fixedRatio` | (页头 + 所有筛选工具栏 + 统计/KPI 区) 高度 ÷ 内容区高度 | **≤ 20%** | ≤ 28% |
| **页头高度** `headerH` | 面板第一个 header 元素的可视高度 | **≤ 44px**（单行标题+说明+动作） | ≤ 48px |
| **筛选区高度** `toolbarH` | 所有 toolbar/filter 行高度之和 | **≤ 48px**（单行）/ ≤ 88px（两行） | 同左 |
| **统计区高度** `statH` | statGrid / 自绘 KPI 区高度 | **≤ 52px**（单行内联 KPI）；**`overview` 例外 ≤96px**（8 张 KPI 卡 × 2 行，单卡 45.9px） | ≤ 52px（`overview` 同左 96px） |
| **空白率** `emptyRatio` | **卡片内容区（cardBd 扣 padding）内连续大块空白**：16px 采样 + 连通分量，空白块 = 宽 ≥ 内容宽 40% 且高 ≥ 48px；背景/padding/gap 不计（`emptyRatioRaw` 为旧的全域采样口径，仅对照） | **≤ 35%** | ≤ 40% |
| **卡片头高度** | `.cardHd` 可视高度 | ≤ 36px | ≤ 36px |
| **表格行高** | 数据行平均高度（含 padding） | 28–34px | 28–34px |

> 密度审计输出每个 tab 的 `headerH / toolbarH / statH / fixedRatio / emptyRatio` 与排名，
> 并对「固定区 > 目标」与「空白率 > 目标」分别标红。低于目标的页面不强制返工。
> **两行筛选（`toolbarRows ≥ 2`）按 ≤88px 判定达标**（单行 48px 只是单行目标；审计里单行阈值仅作诊断）。

## 2. 设计规则（组件级）

### 2.1 页头（`PanelHeader`）
- 标题 15px（`--nm-fs-lg`）600；说明 11px 单行、超长省略号 + `title` 提示；**说明不是必须**——
  与标题重复或只写"本页说明"的一律删。
- 标题、说明、动作**同一行**（`align-items:center`）；动作区靠右、按钮 ≤2 个，其余进「更多 ▾」。
- 禁止在页头里放图标大徽章（42px）、副标题块、重复的 tab 名。
- **页头总高 ≤ 44px**（含 8px 上下呼吸）；带分段条时，分段条并入页头同一行。

### 2.2 筛选/工具栏（`Toolbar`）
- 单行优先：搜索框 `flex:0 1 240px`、时间预设用短标签（今天/本周/本月/近7天/近30天）、排序与导出靠右；
  放不下时**换行但不再加第二层嵌套**，总高 ≤ 88px。
- 删除冗余按钮（例如「搜索」按钮，输入框防抖+Enter 已等价）。
- 日期范围、排序、导出三组之间用 gap 8，不额外加分割线/卡片包裹。

### 2.3 统计卡（`StatCard` / `statGrid`）→ **内联 KPI 条**
- 6 张竖排统计卡（每张 ~110px）是最大浪费源；统一改**单行内联 KPI**：
  `图标 20px + 标签 10.5px + 数值 15px`，每项 `padding 6px 10px`，整条高 **40–46px**。
- 指标 > 6 个时：主 6 个上条，其余收进「更多指标 ▾」或右侧卡片；不再换行堆第二排大卡。
- 语义色只染数值，不染整卡背景；不使用大号 24px 数字（列表场景 15px 足够）。

### 2.4 卡片（`Card`）
- 卡片头 `padding 8px 12px`、标题 13px；`extra` 与标题同一行、右侧对齐；卡片头高 ≤ 36px。
- 卡片体 `padding 12px`（表格卡用 flush）；卡片间距 8px（`gap`），不用 16px。
- 卡片内**唯一滚动容器**：`min-height:0` + `overflow:auto`；禁止卡片自身 `overflow:hidden` 裁内容。
- 卡片最小高度按内容；同排卡片高度可不同，不允许用固定高度撑齐造成空白。
- 「空状态」占位不超过卡片 1/3 高度：空态文案 + 一个主操作即可，禁止整屏居中大插图。

### 2.5 表格（`DataTable`）
- 表头行高 30px、数据行 28–34px；单元格 padding `6px 10px`（密集列表可用 4px 8px）。
- 列优先展示「区分度高」的 4–6 列，其余进详情；数字右对齐、等宽字体。
- 表头 `position:sticky` 时滚动容器不能再 `overflow:hidden`；空表格给一行提示而不是整块占位。

### 2.6 图表/画布卡
- 图表区至少占卡片的 60% 高度；坐标轴/图例字号 10–11px，图例可折叠。
- 禁止给画布固定 300px+ 高度占满屏；按可用高度自适应（`flex:1; min-height:160px`）。

### 2.7 弹层/抽屉
- 弹层内容单滚动容器；头部 44px、底部动作 44px；正文 padding 12–16px。
- 手机档全屏 sheet；桌面宽度 `min(680px, calc(100vw - 32px))`。

## 3. 实施分层（一次改全站，而不是逐页堆补丁）

| 层 | 内容 | 影响面 | 载体 |
|---|---|---|---|
| **A. 全局紧凑 chrome** | 页头/工具栏/卡片头/统计卡/表格行距的 shell 级覆盖（只用 `--nm-*` 令牌，不改 kit 源文件） | 全部 144 面板 | 新建 `ui/compact-chrome.module.css`，在 `WechatDataPanel.tsx` 引入 |
| **B. 顶层面板骨架** | 面板 padding/gap、merged 分段条高度、空态高度 | 全部面板 | `wechat-data.module.css` / `merged*.css`（已有文件，局部调整） |
| **C. 重点面板重塑** | 固定区超标 Top N：删重复说明、合并多行筛选、统计卡→KPI 条、卡片布局重排 | 按密度审计排名逐批（每批 ≤8 文件） | 各 `panels/*.module.css` + 少量 TSX |

**纪律**：A 层必须用**属性选择器 + 标签限定**提高特异性（`div[class*='_panelTitle_']`），
不依赖 CSS 加载顺序；新增间距只用 4/6/8/10/12/16 刻度，不引入 5/7/9/18（主题几何棘轮）。

## 4. 验收清单（每个面板 / 每个 PR）

1. `npm run ui:density-audit` 对比上一版：该面板 `fixedRatio` 达到目标或**只降不升**，`emptyRatio` 不升；
2. `npm run ui:responsive-audit -- --only=<该面板>` 无新增问题（横向溢出/裁切/遮挡/隐藏）；
3. 人工 6 档截图（390/768/1024/1280/1440/2560）：标题不换行、筛选不折成三行、统计区不超过 52px、
   卡片无大块空白、表格行高一致、文字不截断到不可读；
4. 交互仍可用：所有按钮/输入框可达（44px 触摸目标只在手机档要求，桌面不为凑高度硬缩）；
5. 收口链：`typecheck:client` + 受影响 spec + `theme-geometry` / `M21` / 函数行数棘轮全绿；
6. 可读性底线：正文 ≥ 11px、标题 ≥ 13px、对比度沿用现有令牌（不改 `--nm-*` 值）。

## 5. 常见浪费模式与修法（对照表）

| 浪费模式 | 典型表现 | 修法 |
|---|---|---|
| 大统计卡墙 | 6 张竖排 StatCard 占 110–160px | 内联 KPI 条（40–46px） |
| 多行筛选 | 分类/搜索/时间/排序/导出让 Toolbar 折 3 排 | 拆两排紧凑行（如 Records 的做法，144→64px） |
| 页头虚高 | 42px 图标 + h2 上下外边距 + 说明独占一行 | 图标 22px、标题 15px、说明并排省略 |
| 卡片头沉 | cardHd padding 12/16 + 标题 15px | 8/12 + 13px |
| 固定高度撑排 | 同排卡片 `height:100%` 拉齐出大空白 | 内容高度 + 网格对齐（`align-items:start`） |
| 空态整屏 | 空列表居中大图标占满 | 单行提示 + 主操作，居上 1/3 |
| 画布占满 | 图表固定 320px 高、下方空白 | `flex:1; min-height:160px`，卡片吃满可用高 |
| 重复标题 | 卡片头与页头/工具栏重复同名 | 删其一；保留信息量大的 |
